# SmartStat Manufacturing — 제조 현장용 통계 분석 앱 연구 워크스페이스

engineer-research-lifecycle 스킬(F:\obsidian\vault\engineering-research-skill\)을 적용한 증거 기반(evidence-gated) 연구 워크스페이스입니다. 대상 산출물은 「통계분석 앱 제작 기획서.md」(SRC-000)에서 제시된 SmartStat Manufacturing 앱의 MVP 설계 의사결정 근거입니다.

## 목적과 의사결정

품질 비전문가인 제조 현장 실무자가 "현장 문제 → 통계적 판단"으로 이어지는 흐름을 사용할 수 있는 앱을 만들기 위해, (1) 앱의 핵심가치를 검증 가능한 형태로 정의하고 (2) 그 가치를 극대화하는 Analysis Navigator·해석 엔진·결과화면 설계를 근거 기반으로 확정하기 위한 연구입니다.

## 현재 게이트

- Mode: `new`
- Active phase: P0 Contract 승인 대기 / P1 Baseline·P2 Evidence 병행 착수
- Evidence state: 일부 `observed`(1차 문헌·사례 스캔 10건), 대부분 `planned`(1차 현장/사용자 조사 미착수)
- Next admissible action: 헌장(Research_Charter.md) 리뷰어 지정 및 승인, 실제 사내 조립현장 1차 조사(인터뷰/관찰) 설계

## 근거 경고

계획된 방법과 잘 정리된 문서는 실증 결과가 아닙니다. `observed`, `reviewed`, `accepted` 근거를 분리해서 기록하며, 특히 본 워크스페이스는 **실제 사내 가전 조립 현장의 1차 조사(관찰·인터뷰·적용사례)가 아직 수집되지 않은 상태**임을 최우선 제약으로 표시합니다(GAP-06 참조).
