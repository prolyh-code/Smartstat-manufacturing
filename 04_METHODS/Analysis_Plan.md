# Analysis Plan

> 본 문서는 P4(방법 동결) 게이트 이전 골격입니다. 실제 정량 데이터(사용자 조사·프로토타입 테스트 결과)가 수집되기 전까지 아래 항목은 설계 초안이며, 임계값·수용기준은 P4 승인 전 확정하지 않습니다.

## 목표 claim/estimand

- (향후) Navigator 유형(질문식 vs 메뉴식)에 따른 오선택률 차이(H1).
- (향후) 결과화면 정보구조(효과크기 병기 vs p-value 단독)에 따른 올바른 판단 비율 차이(H2).
- (현재 세션) 실제 조립현장 사례와 MVP 기능의 매핑 커버리지(H4) — 기술적 요약(descriptive) 수준.
