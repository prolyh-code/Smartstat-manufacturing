# 분석 패키지 명세 #4 — MSA 패키지 (측정시스템분석)

> CASE-004(문헌)와 CASE-001("측정/판정 근거가 육안·감 수준")에서 공통 확인된 패턴: 공정능력·관리도·비교검정 결론을 측정 자체의 신뢰성 확인 없이 내립니다. 이는 spc-profile.md의 V0(측정시스템) 변동위계 원칙과 정면으로 충돌하며(CLM-16/29), 기획서 Phase1·Phase2 어디에도 MSA 기능이 없다는 구조적 공백이 이미 확인되어 있습니다(FND-11). 이 패키지는 다른 모든 분석 패키지에 **선행되어야 할 "측정을 믿을 수 있는가" 체크리스트**로 설계되었습니다. **런타임에 AI를 호출하지 않습니다.**

## 1. 목적 및 트리거

**트리거 조건**: 사용자가 "측정시스템분석(MSA)" 또는 "Gauge R&R"을 선택하고 표준 Crossed Gauge R&R 형식의 데이터를 업로드했을 때. 또는 [추론, 향후 통합설계 과제] 다른 패키지(결과검증 등) 실행 전 "이 CTQ에 대해 MSA를 먼저 수행한 적이 있는지" 확인하는 진입점으로 연계될 수 있습니다 — 구체적 연계 방식은 GAP-08 해소 후 확정.

## 2. 입력 요구사항

| 항목 | 필수 여부 | 설명 |
|---|---|---|
| 부품 식별자 | 필수 | 통상 10개 부품, 공정 변동 범위를 대표하도록 선정. |
| 작업자/평가자 식별자 | 필수 | 통상 실제로 측정을 수행하는 2~3명. |
| 반복 횟수 | 필수 | 작업자별·부품별 2~3회 반복 측정(무작위·블라인드 권장). |
| 측정값(수치형) | 필수 | 반복측정 각각의 실측값. |

## 3. E2E 처리 흐름

```
Step 0. 데이터 인식        → 부품수·작업자수·반복수 확인, 표준설계(10부품×3작업자×2~3회) 미달 시 경고
Step 1. 시각화             → 작업자별 측정값 박스플롯 + 부품별 산점도(R&R chart)
Step 2. 분산성분 분해       → ANOVA 기반 반복성(EV)·재현성(AV)·부품간변동(PV) 분해
Step 3. %GRR·NDC 판정       → 아래 결정표에 따라 자동 판정
Step 4. 패키지 출력 조립     → 분산성분 표 + 판정 결과 + 해석을 하나의 리포트로 통합
```

### Step 0 표준설계 미달 경고

표준(10부품×3작업자×2~3회)에 미달하는 데이터가 입력되면 결과 자체는 계산하되 "표본설계가 표준(10부품×3작업자×2~3회)에 못 미쳐 %GRR 추정의 신뢰도가 낮을 수 있습니다"라는 경고를 결과 상단에 표시합니다.

### Step 3 결정표 [SRC-134 / AIAG 기준]

| %GRR | NDC | 판정 | 후속 안내 |
|---|---|---|---|
| < 10% | ≥ 5 | **양호** | "이 측정시스템은 신뢰할 수 있는 수준입니다. 이 CTQ로 다른 분석(원인분석·결과검증 등)을 진행해도 좋습니다." |
| 10% ~ 30% | ≥ 5 | **조건부 허용** | "측정오차가 존재하나 용도·비용에 따라 조건부로 허용 가능한 수준입니다. 가능하면 측정방법 개선을 검토하십시오." |
| > 30% 또는 NDC < 5 | — | **불량** | "⚠ 측정시스템 자체의 오차가 커서 신뢰할 수 없는 수준입니다. 측정시스템을 개선하기 전까지는 이 CTQ로 도출하는 다른 모든 통계 분석 결과(관리도·검정·회귀 등)의 신뢰성이 낮습니다." |

## 4. 해석 템플릿 라이브러리 (슬롯 기반)

**슬롯 정의**: `{%GRR}`, `{NDC}`, `{판정}`(양호/조건부/불량), `{설계미달경고}`(있음/없음), `{반복성비중}`, `{재현성비중}`

| 판정 | 설계미달경고 | 템플릿 |
|---|---|---|
| 양호 | 없음 | "%GRR={%GRR}%, NDC={NDC} — 측정시스템이 양호합니다. 이 CTQ에 대한 다른 분석 결과를 신뢰할 수 있습니다." |
| 조건부 | 없음 | "%GRR={%GRR}%, NDC={NDC} — 조건부 허용 수준입니다. 반복성({반복성비중}%)과 재현성({재현성비중}%) 중 더 큰 쪽을 우선 개선 대상으로 검토하십시오." |
| 불량 | 없음 | "⚠ %GRR={%GRR}%, NDC={NDC} — 측정시스템이 신뢰할 수 없는 수준입니다. 다른 분석에 앞서 측정방법 개선이 필요합니다." |
| — | **있음** | "⚠ 표본설계가 표준에 못 미쳐({설계미달경고}) 위 수치의 신뢰도가 낮을 수 있습니다. 가능하면 표준설계(10부품×3작업자×2~3회)로 재측정 후 재확인하십시오." (판정 템플릿과 함께, **먼저** 표시) |
| (매칭 실패 시 기본값) | | "이 조합에 대한 표준 해석 문구가 아직 준비되지 않았습니다. 수치 결과(%GRR={%GRR}%, NDC={NDC})를 직접 확인하시거나 통계 담당자에게 문의하십시오." — **필수 포함** |

## 5. PRISM 연동 관련 미확정 사항 (GAP-08 — DEC-009로 본 연구범위 제외)

Ian의 지시에 따라 PRISM의 기술 스택·데이터 스키마·API는 이 연구 단계에서 조사하지 않으며, Claude Code 개발 착수 시 최종 지침서·앱 폴더와 함께 직접 전달됩니다. 특히 이 패키지는 (1) MSA 결과를 CTQ별로 저장해두었다가 다른 패키지 실행 시 "이 CTQ는 MSA 미수행/불량 판정"임을 자동으로 경고에 반영하는 통합 아키텍처가 이상적이나, 이는 PRISM의 데이터 저장 구조를 알아야 설계 가능하므로 지금은 각 패키지가 독립적으로 동작하는 것으로 가정합니다.

## 6. 다른 패키지에 적용할 재사용 패턴

이 패키지의 판정 결과("불량 시 다른 분석 신뢰성 저하 경고")는 향후 통합설계 시 **모든 패키지의 공통 선행 체크리스트**로 승격시킬 것을 제안합니다(GAP-08 해소 후 구체화). 결정표+슬롯템플릿 구조는 다른 패키지와 동일 패턴을 따릅니다.
