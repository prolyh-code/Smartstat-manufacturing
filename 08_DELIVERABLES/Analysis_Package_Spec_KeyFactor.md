# 분석 패키지 명세 #3 — 핵심요인분석 패키지

> CASE-001("파라미터를 하나씩 조정해보며 감으로 판단")과 CASE-006(문헌)에서 공통 확인된 패턴: 여러 공정변수 중 실제로 CTQ에 영향을 주는 소수의 핵심요인(vital few)을 한 번에 하나씩(OFAT) 시행착오로 찾습니다. 본격적인 DOE(실험계획법)는 기획서상 Phase3 범주로 이 패키지의 범위 밖이지만, Phase1의 단순회귀를 다중회귀로 확장하면 기존에 수집된 데이터만으로도 핵심요인을 좁힐 수 있습니다. **런타임에 AI를 호출하지 않습니다.**

## 1. 목적 및 트리거

**트리거 조건**: 사용자가 결과변수(연속형 CTQ) 1개와 후보 설명변수(연속형 공정변수) 2개 이상을 업로드하고 "핵심요인분석" 목적을 선택했을 때.

## 2. 입력 요구사항

| 항목 | 필수 여부 | 설명 |
|---|---|---|
| 결과변수(수치형) | 필수 | 영향을 받는 CTQ 또는 공정변수 1개 열. |
| 후보 설명변수(수치형) | 필수(2개 이상) | 온도·압력·속도·토크 등 연속형 공정변수. |
| 관측단위 식별자 | 선택 | 로트/배치 등 — 결과 해석 시 참고용. |

## 3. E2E 처리 흐름

```
Step 0. 데이터 인식        → 표본수(n) 대 변수 개수 비율 확인(n < 10×변수수면 경고)
Step 1. 시각화             → 변수쌍 산점도 매트릭스 + 상관계수 히트맵 자동 생성
Step 2. 다중공선성 체크     → VIF(분산팽창계수) 계산, VIF>5 변수 경고
Step 3. 다중회귀 실행       → 결과변수 ~ 전체 후보 설명변수 회귀적합
Step 4. 핵심요인 선별+순위화 → p<0.05 변수만 선별, 표준화계수 절댓값 기준 순위화
Step 5. 모형적합도 평가     → R²/adj R² 확인, 저설명력 시 경고
Step 6. 패키지 출력 조립    → 1~5 전체를 "핵심요인 순위표"로 통합
```

### Step 2 다중공선성 결정표 [SRC-137 근거]

| VIF 값 | 판정 | 처리 |
|---|---|---|
| VIF < 5 | 문제없음 | 그대로 회귀에 포함 |
| VIF ≥ 5 | 다중공선성 의심 | 경고 표시 + "관련 변수 중 하나를 제거하거나 두 변수를 결합한 새 지표를 만드는 것을 검토하십시오" 안내 (자동 제거는 하지 않음 — 어떤 변수를 남길지는 공정 지식이 필요한 판단이므로 사용자 결정 영역) |

### Step 4 핵심요인 선별 결정표 [SRC-137 근거]

| p-value | 판정 |
|---|---|
| p < 0.05 | 통계적으로 유의한 요인 → 표준화계수 절댓값 기준 순위 부여 |
| p ≥ 0.05 | 이번 데이터로는 유의한 영향이 확인되지 않음 → 순위표에서 제외하되 "영향이 없다"가 아니라 "확인되지 않았다"로 표기 |

### Step 5 모형적합도 경고

adj R² < 0.5(예시 기준, [추론] — 절대기준 아님) 이면 "선택된 변수들만으로는 결과변수의 변동을 충분히 설명하지 못합니다. 고려하지 않은 다른 요인이 있거나, 변수 간 상호작용 효과가 있을 수 있습니다(다중회귀는 상호작용을 자동으로 포함하지 않습니다 — 필요 시 DOE 검토를 권장)"라는 경고를 표시합니다.

## 4. 해석 템플릿 라이브러리 (슬롯 기반)

**슬롯 정의**: `{요인명}`, `{순위}`, `{표준화계수}`, `{p값}`, `{VIF경고}`(있음/없음), `{모형적합도등급}`(양호/부족)

| 모형적합도 | VIF경고 | 템플릿 |
|---|---|---|
| 양호 | 없음 | "핵심요인 {순위}순위: {요인명}(표준화계수={표준화계수}, p={p값}). 이 요인의 변화가 결과변수에 가장 큰 영향을 미치는 것으로 나타났습니다." |
| 부족 | 없음 | "선택된 변수들의 설명력이 낮습니다. 아래 순위는 참고용이며, 다른 후보요인 추가 또는 실험계획법(DOE) 검토를 권장합니다." (다른 템플릿보다 **우선 표시**) |
| — | **있음** | "⚠ 일부 변수 간 상관관계가 높아({VIF경고}) 개별 요인의 순수한 영향력 구분이 어려울 수 있습니다. 변수 정리 후 재분석을 권장합니다." (모형적합도 템플릿보다도 **먼저 표시**) |
| (매칭 실패 시 기본값) | | "이 조합에 대한 표준 해석 문구가 아직 준비되지 않았습니다. 수치 결과(표준화계수={표준화계수}, p={p값})를 직접 확인하시거나 통계 담당자에게 문의하십시오." — **필수 포함** |

## 5. PRISM 연동 관련 미확정 사항 (GAP-08 — DEC-009로 본 연구범위 제외)

Ian의 지시에 따라 PRISM의 기술 스택·데이터 스키마·API는 이 연구 단계에서 조사하지 않으며, Claude Code 개발 착수 시 최종 지침서·앱 폴더와 함께 직접 전달됩니다. 미확정 항목: PRISM이 이미 보유한 다변량 공정변수 이력 데이터를 이 패키지가 직접 조회할 수 있는지, 사용자가 매번 별도 업로드해야 하는지.

## 6. 다른 패키지에 적용할 재사용 패턴

Step 5의 "낮은 설명력 → 참고용 경고" 패턴은 원인분석 패키지의 "비유의 → 확인 안 됨" 템플릿과 동일한 설계 원칙(과잉확신 방지)을 공유합니다. DOE는 이 패키지의 범위 밖이지만, 향후 별도 패키지("실험계획 패키지")로 확장할 경우 이 패키지의 산출물(핵심요인 순위)을 실험 인자 후보 목록의 입력으로 재사용할 수 있습니다.
