# 분석 패키지 명세 #7 — 신뢰성/수명분석 패키지

> Ian이 DEC-012로 착수를 직접 결정한 패키지입니다. 소모성 부품(예: 필터, 벨트, 모터 등)의 사용시간·고장이력 데이터로부터 고장 패턴(마모성/우발/초기고장)을 판정하고, 부품의 예상 수명(MTBF·특성수명)을 산출합니다. **런타임에 AI를 호출하지 않습니다.**
>
> **[근거등급 고지]** 이 패키지는 기존 6개 패키지보다 문헌조사가 얕은 상태(1라운드, SRC-147/149/150)에서 설계되었습니다. 통계적으로도 기존 6개 패키지보다 전문적인 영역(중도절단 데이터, 파라미터 추정)이므로, Ian 또는 통계 담당자의 검토를 거친 뒤 배포하는 것을 권장합니다.

## 1. 목적 및 트리거

**트리거 조건**: 사용자가 "부품 수명/교체주기 파악" 목적을 선택하고, 부품별 사용시간(또는 사용량)과 고장 여부(고장/아직 정상) 데이터를 업로드했을 때. CASE-002(문헌)에서 확인된 "소모성 부품의 경험적 교체주기 설정" 니즈에 대응합니다.

## 2. 입력 요구사항

| 항목 | 필수 여부 | 설명 |
|---|---|---|
| 부품/설비 식별자 | 필수 | 어떤 부품인지(예: 필터 A, 벨트 B). |
| 사용시간 또는 사용량(수치형) | 필수 | 고장까지(또는 현재까지) 누적된 사용시간·사이클·생산량 등. |
| 고장 여부 | **필수** | 고장(관측완료) vs 아직 정상(중도절단/suspension) — 이 구분이 없으면 Weibull 추정이 불가능하므로 다른 패키지와 달리 생략 불가. |
| 표본수 | — | 최소 권장 표본수(고장+중도절단 합계 15건 이상)에 미달 시 경고 표시(Step 0). |
| 계획 교체비용(CP)·현장고장비용(CU) | 선택 | 교체주기 최적화(Step 5, M-RELY-REPLACEINTERVAL)를 원할 때만 입력. 없으면 Step 5는 건너뛰고 정비전략 판정(Step 2)까지만 제공. |

## 3. E2E 처리 흐름 (결정론적, 사용자 개입 없이 전부 자동 실행)

```
Step 0. 데이터 인식(M-RELY-DATAPROFILE)   → 고장 n건/중도절단 m건 확인, 표본수 부족 시 경고
Step 1. Weibull 파라미터 추정(M-RELY-WEIBULLFIT) → 중도절단 비중에 따라 MLE/순위회귀 자동 선택, β·η 산출
Step 2. 정비전략 판정(M-RELY-STRATEGY)     → β값 기반 3단 결정표 적용
Step 3. 신뢰도함수·특성수명 산출(M-RELY-RELFUNC) → R(t) 곡선, 특성수명(63% 고장시점)
Step 4. MTBF 산출(M-RELY-MTBF)            → μ=η×Γ(1+1/β), β≠1이면 한계 경고 부착
Step 5. 교체주기 최적화(M-RELY-REPLACEINTERVAL) → β>1이고 CP·CU 입력 있을 때만 실행, CPUT 최소화 t* 산출
Step 6. 해석 조립(M-INTERP-ASSEMBLE)       → 아래 §4 템플릿 적용
Step 7. 안전 폴백(M-SAFETY-FALLBACK)
```

### Step 0 표본수 부족 경고

고장+중도절단 합계가 15건 미만이면 "데이터가 아직 충분하지 않아({표본수}건) Weibull 추정의 신뢰구간이 넓을 수 있습니다. 가능하면 더 많은 부품의 이력을 모아 재분석하십시오"라는 경고를 표시하되, 계산 자체는 진행합니다. [추론, 임계값 15건은 통계적 최소 표본 관행을 참고한 설계 확장 — 문헌에서 명시적 수치 확인은 안 됨]

### Step 2 결정표 (형상모수 β 기반, [SRC-147/CLM-41 근거])

| β 범위 | 판정 | 의미 |
|---|---|---|
| β > 1 (뚜렷하게, 예: >1.2) | 마모성 고장 | 시간이 지날수록 고장 위험 증가 — 예방정비(정기 교체)가 효과적 |
| β ≈ 1 (예: 0.8~1.2) | 우발고장(일정 고장률) | 새 부품이나 오래된 부품이나 고장 확률이 비슷함 — 예방정비 효과 낮음, 상태기반(고장 시 교체) 전략이 더 합리적일 수 있음 |
| β < 1 (뚜렷하게, 예: <0.8) | 초기고장 | 불량품이 초기에 걸러지는 패턴 — 신품 선별검사·번인테스트 검토 필요 |

[추론] β 임계값 구간(1.2/0.8)은 SRC-147에 명시된 정확한 수치가 아니라 "β>1/β≈1/β<1" 3단 서술을 실무에서 적용 가능한 구간으로 변환한 설계 확장입니다 — 통계 담당자 검토 권장.

### Step 5 교체주기 최적화 (M-RELY-REPLACEINTERVAL, [SRC-153/CLM-47 근거])

**적용 조건**: β>1(마모성 고장 판정) **그리고** 사용자가 CP(계획 교체비용)·CU(현장고장비용)를 모두 입력했을 때만 실행합니다. β≈1(우발고장)이나 β<1(초기고장)일 때는 예방적 정기교체 자체가 비용상 의미가 없으므로 이 모듈을 실행하지 않고, 그 사유를 안내 문구로 대신합니다(§4).

**결정로직**: 후보 교체주기 t의 그리드(예: 0.1×η ~ 2×η 범위를 등간격 분할)에 대해 주기당비용 CPUT(t) = [CP×R(t) + CU×(1−R(t))] / [t×R(t) + M(t)×(1−R(t))]를 계산하고, CPUT(t)가 최소인 t를 t*(권장 교체주기)로 선정합니다. 여기서 R(t)는 Step 3 신뢰도함수, M(t)는 t 이전에 고장났을 경우의 기대 고장시점입니다.

**[추론/설계 확장 — 중요]** SRC-153(ReliaSoft)의 원문은 미분을 이용한 해석적 최적화를 설명하지만, 본 연구는 무AI·결정론적 규칙 엔진이라는 제약 하에서 구현이 상대적으로 쉬운 **그리드 탐색(수치 비교)** 방식으로 단순화했습니다. 그리드 간격·범위 설정에 따라 해석적 최적해와 오차가 발생할 수 있으므로, Claude Code 개발단계에서 그리드 해상도를 검증하거나 필요시 수치적분·수치미분으로 정밀도를 높이는 것을 권장합니다. M(t) 계산(불완전감마함수 적분)의 구체적 수치기법 선택도 개발단계 과제로 남깁니다.

## 4. 해석 템플릿 라이브러리 (슬롯 기반, GAP-09 방법론 적용)

**슬롯 정의**: `{부품명}`, `{β값}`, `{η값}`, `{정비전략}`(마모성/우발/초기고장), `{특성수명}`, `{MTBF}`, `{MTBF경고}`(있음/없음 — β≠1일 때), `{표본부족경고}`(있음/없음), `{권장교체주기}`(Step 5 적용 시에만 존재), `{교체주기안내}`(있음/없음/해당없음 — 목록형 조립 성격의 부가 슬롯)

**슬롯 유형 판정**: 정비전략(3종)은 **배타적 핵심분류**(β 하나의 값에서 하나의 구간만 해당), 표본부족경고·MTBF경고는 **접두 경고**(핵심분류와 독립, 있으면 항상 먼저 표시), 교체주기안내는 **목록형 조립**(정비전략이 "마모성"이고 CP·CU 입력이 있을 때만 추가로 등장하는 조건부 부가정보 — 있으면 핵심분류 템플릿 뒤에 이어 붙이고, 없으면 아예 생략) — Analysis_Module_Library_and_Composition_Rules.md §2.7의 일반 규칙을 그대로 적용.

| 정비전략 | 템플릿 |
|---|---|
| 마모성 고장 | "{부품명}은 사용시간이 늘어날수록 고장 위험이 커지는 마모성 패턴을 보입니다(β={β값}). 특성수명은 약 {특성수명}이며, 이 시점 전에 예방적으로 교체하는 정기 교체 전략이 효과적일 것으로 보입니다. MTBF(평균 고장간격)는 약 {MTBF}입니다." |
| 우발고장 | "{부품명}은 사용시간과 무관하게 고장 확률이 비교적 일정한 패턴을 보입니다(β={β값}). 이 경우 정기 교체보다 고장 발생 시 즉시 교체하는 상태기반 전략이 더 합리적일 수 있습니다. 평균 고장간격(MTBF)은 약 {MTBF}입니다." |
| 초기고장 | "{부품명}은 사용 초기에 불량품이 걸러지는 패턴을 보입니다(β={β값}). 신품 단계에서 선별검사나 번인(초기가동) 테스트를 도입하면 초기 고장을 줄일 수 있는지 검토해보십시오." |
| — (표본부족경고 **있음**) | "⚠ 데이터가 아직 충분하지 않아({표본수}건) 아래 판정의 신뢰구간이 넓을 수 있습니다. 더 많은 이력이 쌓인 후 재확인을 권장합니다." (다른 템플릿보다 **우선 표시**) |
| — (MTBF경고 **있음**, β≠1) | "참고: MTBF는 평균값 하나로 요약한 수치이므로, 실제로는 위에서 설명한 고장 패턴(β={β값})에 따라 시간대별 고장 위험이 다릅니다. MTBF만으로 교체 시점을 결정하기보다 위 설명을 함께 참고하십시오." (핵심분류 템플릿 뒤에 이어 붙임) |
| — (교체주기안내, 정비전략=마모성 **그리고** CP·CU 입력 있음) | "비용을 함께 고려하면, 약 {권장교체주기} 시점에 교체하는 것이 계획교체 비용과 현장고장 비용을 합한 총비용을 가장 낮추는 것으로 계산됩니다(그리드 탐색 기반 추정치이므로 참고용으로 활용하십시오)." (마모성 고장 템플릿 뒤에 이어 붙임) |
| — (정비전략=우발/초기고장 **그리고** CP·CU 입력 있음) | "참고: 이 부품은 예방적 정기교체의 비용 이점이 크지 않은 고장 패턴이므로, 입력하신 비용 정보로는 별도의 권장 교체주기를 계산하지 않았습니다." (CP·CU를 입력했는데도 계산되지 않는 이유를 설명 — 목록형 조립 원칙상 빈 결과를 그냥 생략하면 사용자가 오류로 오인할 수 있어 명시적으로 안내) |
| (매칭 실패 시 기본값) | "이 조합에 대한 표준 해석 문구가 아직 준비되지 않았습니다. 수치 결과(β={β값}, η={η값})를 직접 확인하시거나 통계 담당자에게 문의하십시오." — **필수 포함** |

**전수화 확인**: 정비전략 3종(배타적) × 표본부족경고 2종(접두) × MTBF경고 2종(접두, β=1일 때는 자동으로 "없음"이므로 실질적으로 항상 발생) × 교체주기안내 3종(목록형 조립 — 마모성+비용입력 시 "권장주기 제시" / 우발·초기고장+비용입력 시 "계산 안 함 안내" / 비용 미입력 시 "생략") = 핵심분류 3개+접두경고 2개+교체주기안내 2개+폴백 1개, 총 8개 구성요소로 조합을 전부 커버(그리드 탐색 결과가 없는 경우까지 포함해 빈 결과가 그냥 누락되지 않도록 설계).

## 5. PRISM 연동 관련 미확정 사항 (GAP-08 — DEC-009로 본 연구범위 제외)

Ian의 지시에 따라 PRISM의 기술 스택·데이터 스키마·API는 이 연구 단계에서 조사하지 않습니다. 특히 이 패키지는 부품별 "누적 사용시간" 데이터를 PRISM이 이미 추적하고 있는지, 아니면 사용자가 별도로 입력해야 하는지가 설계에 큰 영향을 미치므로, 이는 GAP-08 해소 시점(Claude Code 개발 착수)에 최우선으로 확인해야 할 항목으로 기록합니다.

## 6. 미해결 항목 (GAP-10 잔여 — 2026-09-10 축소)

- **[해소됨]** M-RELY-REPLACEINTERVAL(비용비 기반 최적 교체주기 산출): SRC-153(ReliaSoft CPUT 방정식) 확보로 결정로직을 확정하고 §3 Step 5·§4 템플릿에 통합했습니다. 단, 원문의 해석적(미분) 최적화 대신 그리드 탐색으로 단순화한 부분은 [추론]/설계 확장이며 개발단계 수치검증이 필요합니다(§3 Step 5 참조). SRC-148(본문 미열람)은 더 이상 필수 근거가 아닙니다.
- **[잔여]** β 판정 구간(1.2/0.8)이 [추론]으로 표시된 설계 확장이므로, 통계 담당자 검토 후 조정 가능성이 있습니다.
- **[신규 잔여]** 그리드 탐색의 구간·해상도(예: 0.1×η~2×η, 몇 개 구간으로 나눌지)는 이 명세에서 예시 수준으로만 제시했으며, 개발단계에서 계산 정밀도와 성능(계산량)을 함께 고려해 확정해야 합니다.

## 7. 다른 패키지에 적용할 재사용 패턴

M-INTERP-ASSEMBLE·M-SAFETY-FALLBACK은 기존 6개 패키지와 동일하게 재사용됩니다. 신규 모듈(M-RELY-*)은 이 패키지 전용이지만, "배타적 핵심분류(β 구간)+접두경고(표본부족·MTBF한계)+목록형 조립(교체주기안내, 조건부로만 등장)" 조립 패턴은 GAP-09 방법론(Analysis_Module_Library_and_Composition_Rules.md §2.7)을 그대로 따른 것으로, 향후 비용 기반 최적화가 필요한 다른 패키지(예: 재고 관련 확장)에도 동일하게 적용할 수 있습니다.
