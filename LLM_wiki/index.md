## 문서 교차 링크 규칙

- 원천 문서와 추상화 문서를 구분하여 링크한다.
- 인덱스의 목적은 빠른 탐색이지 문서 내용 복제이지 않는다.
- 업데이트 시 메타데이터와 연계 문서 목록을 함께 갱신한다.

## 메타 데이터 규칙

- 파일 경로와 문서의 실제 진짜 위치를 기준으로 참조한다.
- 파일명에 공백이 있을 경우 링크는 URL 인코딩된 형태를 쓴다.
- 관련 문서가 추가되면 이 인덱스에 연결 엔트리를 추가한다.
