       ↓

Independent?

를 확인합니다.

```

```

합니다.

# 25-12. Agent Orchestrator

가장 중요한 클래스입니다.

```
class AgentOrchestrator:

    def run(
        self,
        session: AnalysisSession
    ) -> AnalysisSession:

        while not self.stop_engine.should_stop(session):

            context = self.context_builder.build(session)

            decision = self.llm.decide(context)

            validation = self.rule_engine.validate(
                decision,
                session
            )

            if validation.rejected:
                decision = self.repair(decision, validation)
                continue

            result = self.execute(decision)

            validated_result = self.result_validator.validate(
                result
            )

            self.state_manager.update(
                session,
                validated_result
            )

            self.interpret(session)

            self.next_action(session)

        return session
```

이것이 앞서 설계한 Agent State Machine을 실제 코드로 표현한 것입니다.
